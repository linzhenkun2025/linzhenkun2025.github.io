学习笔记｜LoRA Without Regret：监督学习与强化学习各需要多少容量

2026-06-15
  • LoRA
  • 微调
  • 强化学习
  • 阅读笔记

原文：LoRA Without Regret — Thinking Machines 重点章节：How much capacity is needed by supervised and reinforcement learning

一句话总结

LoRA 不是天生比全量微调（FullFT）差。只要满足两个条件——(1) 把 LoRA 加在所有参数密集层（MLP/MoE，而不只是 attention）；(2) 可训练参数量超过任务所需的信息量——LoRA 就能在样本效率和最终性能上追平 FullFT。作者把这个区间称为 “low-regret regime”（无悔区间）。

一、核心结论速览

# 结论 关键点
1 容量决定上限 数据集信息量超过 LoRA 容量时才会掉点，是”存不下”而非有性能硬墙
2 必须加在所有层 只加 attention 显著差于只加 MLP，即使参数量相同
3 对 batch size 更敏感 batch 越大，LoRA 相对 FullFT 的 loss 惩罚越大（来自 BA 乘积参数化）
4 RL 几乎不需要容量 即使 rank 很小，RL 上 LoRA 也能等价 FullFT
5 学习率高约 10× LoRA 的最优学习率稳定地约为 FullFT 的 10 倍

二、为什么”容量”是核心？

作者用信息论来估算任务真正需要多少可训练参数。

监督学习（SFT）

用 log-loss 估计需要记忆的信息量：LLM 数据集通常每 token 约 1 bit（0.69 nats） 的 loss。把”记忆整个数据集”作为容量上界。

⚠️ 注意：这是记忆的上界，泛化实际需要的远小于此——作者承认这是留给未来的开放问题。

强化学习（RL）：著名的”1 bit / episode”论证

这是全文最精彩的容量分析。结论：策略梯度每个 episode 大约只吸收 O(1) bit 信息，与模型大小无关。

推导核心：REINFORCE 更新为

G = S ⋅ Adv,  S = ∇log pθ(τ)

给定 history，S 与奖励 R 无关，唯一依赖 R 的只有标量 advantage。于是用互信息 + 数据处理不等式：

I(G; R ∣ history) ≤ H(Adv) ≲ log (B)

（B 是 advantage 量化的桶数）。每个 episode 信息量是 O(1)，与参数量无关。

算一笔账：

  • 训练 ~10,000 道题 × 每题 32 个采样 ≈ 320,000 bits 总信息
  • Llama-3.1-8B 的 rank-1 LoRA 就有 300 万参数，几乎是上述信息量的 10 倍
  • 更大规模的 DeepMath：5.3M episodes ≈ 5.3M bits，仍低于低秩 LoRA 容量

👉 这解释了为什么”reasoning / RL 训练用小 rank LoRA 就够”。

三、为什么要加在所有层，而不只是 attention？

“Attention-only LoRA significantly underperforms MLP-only LoRA” —— 即使把参数量对齐也是如此。

MLP/MoE 才是参数密集、承载知识的地方。只在 attention 上加低秩适配，等于把容量放错了位置。

四、关于 rank 的一个优雅性质

LoRA 更新写作：

$$W' = W + \frac{\alpha}{r} BA$$

由于有 1/r 缩放，每一项的期望更新与 rank 无关——所以不同 rank 的早期学习曲线会重合。差异只在数据量超过容量后才显现。

五、Batch size 的”暗坑”

在 OpenThoughts3 的 10k 子集实验中：batch size 到 128 时，LoRA 与 FullFT 的差距变得持续存在并随训练扩大。

关键：这是 BA 乘积参数化的优化动力学问题，不是 rank 不够。增大 rank 救不了它。

六、超参数：四个旋钮其实只有二维

作者证明 LoRA 名义上 4 个超参，实际只有 2 维自由度。存在如下不变变换：

$$\alpha \to \tfrac{1}{pq}\alpha,\quad \text{init}_A \to p\,\text{init}_A,\quad LR_A \to p\,LR_A,\quad LR_B \to q\,LR_B$$

这统一解释了：

  • LoRA+（A/B 用不同学习率）
  • Unsloth 建议的”更大 α”

它们其实是在同一个 2D 空间里的等价移动。

学习率经验： 长训练中 LoRA 最优 LR ≈ FullFT 的 10×；短训练（~100 步）可达 ~15×，因为 B 初始化为 0 形成了隐式 warmup。

七、计算成本

LoRA 每次 pass 约为 FullFT 的 2/3 FLOPs：

  • FullFT：3N2 乘加（前向 + 两次反向）
  • LoRA：2N2 + 6NR 乘加（原矩阵前向 + 廉价的 A/B 更新）

当 R ≪ N 时即为 2:3。

八、我的 takeaway

  1. “LoRA 差”往往是用错了：没加全层、rank 配得太离谱、或 batch 太大。先排查这三点。
  2. RL/reasoning 场景大胆用小 rank——信息论给了底气，rank-1 都可能够用。
  3. 调 LR 时直接从 FullFT 的 10 倍起步，省掉一轮 sweep。
  4. 大 batch + LoRA 要警惕：这是参数化的本质限制，别指望加 rank 解决。
